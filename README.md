### Projects

**[AI-Governance-Assistant](https://github.com/YasYendluri21/AI-Governance-Assistant)**
Natural-language governance requests become structured, validated, human-approved policy configs.
A four-step agent workflow with a real human checkpoint — the run persists and resumes rather than
holding a continuation in memory — plus an observability dashboard covering run status, failures by
step, latency and audit history. React, TypeScript, Node, Claude API, optional S3 archival.

**[lattice-design-system](https://github.com/YasYendluri21/lattice-design-system)**
An accessible React component library driven by design tokens, with marketing pages composed from a
headless CMS over GraphQL. Tokens compile into the Tailwind theme, so no component can introduce a
value design did not define. Eleven components documented in Storybook, verified at WCAG 2.1 AA by
axe in the Playwright suite. Next.js, TypeScript, Tailwind.

**[realtime-chat](https://github.com/YasYendluri21/realtime-chat)**
Rooms, live presence and message history. Next.js, TypeScript, Socket.IO.

**[fullstack-trpc-prisma](https://github.com/YasYendluri21/fullstack-trpc-prisma)**
End-to-end type safety from the database through to component props. Next.js App Router, tRPC,
Prisma.

**[i18n-nextjs-starter](https://github.com/YasYendluri21/i18n-nextjs-starter)**
Device-locale detection, persisted preference, and a CI check that fails the build when locale keys
drift out of parity.

**[aws-s3-uploader](https://github.com/YasYendluri21/aws-s3-uploader)**
Direct-to-S3 uploads with presigned URLs. Next.js, AWS SDK v3.
